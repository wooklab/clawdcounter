# ClawdCounter

[한국어](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

Claude の使用量の上限(5時間 / 週間)と、ローカルの Claude Code セッションの状況を macOS のメニューバーにひと目で表示する非公式アプリです。Anthropic とは無関係で、文書化されていないエンドポイントを利用しているため、いつ変更・遮断されてもおかしくありません。UI は韓国語、英語、簡体字中国語、日本語に対応しています。

## 機能

- **メニューバーの表示**: `5時間 上限の残り時間 | [5時間バー / 週間バー] | ● アクティブ数 / ○ 非アクティブ数 | ✋ 応答待ち`
  - 5時間枠がアクティブでない場合は残り時間の位置に `–` が表示され、5時間の上限自体がない場合は週間バーのみが表示されます。
  - `✋` は応答待ちのセッションがあるときだけ付き、2件以上ある場合は件数も一緒に表示されます。
  - ログアウト状態では `ログインが必要`、有効期限が切れると `再ログインが必要` と表示されます。
- **使用率の4段階の色**: バーとドロップダウンの色は、画面に表示される整数のパーセント(四捨五入)を基準にしています。

  | 使用率 | 色 |
  |---|---|
  | 0–49% | 緑 |
  | 50–79% | 黄 |
  | 80–94% | オレンジ |
  | 95% 以上 | 赤 |

- **ドロップダウン**(区切り線でセクションを分割)
  1. 上限: 5時間 / 週間 / Fable。バー、パーセント、残り時間。API の応答に該当する上限がない場合、その行は表示しません。
  2. クレジット: 追加使用(クレジット)の金額。総量が分かる場合は `使用額 / 総量`。
  3. セッション: 状態ごとのヘッダーとセッション名の一覧(状態ごとに最大8件、超過分は `他 N 件`)。
  4. Claude にログイン / Claude からログアウト、設定(ログイン時に自動起動、使用量の更新間隔 1・2・5分、言語)。
  5. 終了。
- **セッションの3つの状態**: ● アクティブ(緑) / 応答待ち(メニューバーは ✋、ドロップダウンは黄色の ●) / ○ 非アクティブ。実行中のサブエージェントはアクティブなセッションに1件ずつ加算され、`↳ 説明` として並びます。
- **セッション名のクリック**: そのセッションが動いているアプリ(ターミナル、VS Code、Claude デスクトップなど)を最前面に表示します。
- **多言語対応**: 韓国語、English、简体中文、日本語の4言語に対応しています。デフォルトはシステムの言語に従い、設定から言語を変更できます。

## 注意 / 免責

- **Anthropic とは無関係の非公式アプリ**です。Anthropic が作成したものでも、保証するものでもありません。
- 使用量取得 API(`api.anthropic.com/api/oauth/usage`)と OAuth クライアント ID は、インストール済みの Claude Code から確認した**非公式の値**です。文書化された公開 API ではないため、**いつ変更・遮断されてもおかしくなく**、その場合はアプリが動作しなくなる可能性があります。
- このアプリの利用に伴うアカウント関連の問題について、保証および責任は負いません(LICENSE を参照)。

## 動作要件

- macOS 14 以上
- Xcode と Swift 6 ツールチェーン (`swift-tools-version: 6.0`)

## インストール / ビルド

```sh
git clone https://github.com/wooklab/clawdcounter.git
cd clawdcounter
scripts/build_app.sh        # 結果: build/ClawdCounter.app
open build/ClawdCounter.app
```

アプリはメニューバー専用(`LSUIElement`)のため、Dock アイコンはありません。

### 初回起動時の警告

ビルドスクリプトは一時的な(ad-hoc)署名(`codesign --sign -`)しか行いません。自分でビルドしたアプリは通常、警告なしで起動しますが、他の場所からダウンロードしたアプリや、圧縮して移動したアプリでは Gatekeeper の警告が表示されることがあります。その場合は、次のいずれかを実行してください。

- Finder で `build/ClawdCounter.app` を右クリック → **開く**
- または `xattr -dr com.apple.quarantine build/ClawdCounter.app`

`xattr` コマンドは**自分でビルドしたアプリにのみ**使用してください。出所の分からないアプリには使わないでください。

### キーチェーンの確認ダイアログ

ログインすると、トークン(アクセス/リフレッシュ)をアプリ専用のキーチェーン項目 `ClawdCounter-credentials` に保存します。アプリを再ビルドまたは更新すると一時署名が変わるため、キーチェーンアクセスの確認ダイアログが再び表示されることがあります。その場合は **常に許可** を選択してください。

## 使い方

1. アプリを起動すると、メニューバーに `ログインが必要` と表示されます。
2. メニューバーの項目をクリックし、**Claude にログイン** を選択します。デフォルトのブラウザが開き、ログインが完了するとアプリが自動的に使用量を取得します。
3. ローカルのコールバックサーバーを開けない場合は、ブラウザに表示されるコードをアプリに貼り付ける方式に切り替わります。
4. 使用量はデフォルトで1分ごとに更新され(設定で 1・2・5分)、メニューを開いたときにも更新されます。
5. 設定 → 言語で表示言語を変更できます。変更はメニューバー、ドロップダウン、設定ウィンドウにすぐ反映されます。

## プライバシー

**読み取るローカルファイル**(すべて読み取り専用)

- `~/.claude/sessions/*.json`: セッションの状態(`status`)、名前、作業ディレクトリ、セッション ID など
- `~/.claude/projects/*/<sessionId>/subagents/*.meta.json`: サブエージェントの説明と終了の有無
- 同じ場所にあるサブエージェントの `jsonl` ファイルは**更新日時のみ**を確認し、内容は読みません。

**ネットワーク**

- ログイン: `claude.com`(ブラウザで認証ページを開く)、`platform.claude.com`(トークンの発行/更新/失効)
- 使用量の取得: `api.anthropic.com`
- サードパーティのサーバーへの送信や、分析/テレメトリの送信は一切ありません。

**認証情報**

- Claude Code の認証情報(キーチェーン項目、`~/.claude` 内の認証情報)は読み書きしません。アプリ独自の OAuth ログインで取得したトークンのみを使用します。
- **ログアウト**すると、アプリのトークンをキーチェーンから削除し、サーバーにトークンの失効を試みます(失敗してもローカルの削除は維持されます)。

**アプリがディスクに書き込むもの**

- `~/Library/Application Support/ClawdCounter/last_usage_raw.json`: デバッグ用に、**最後の使用量 API 応答の原文**を上書き保存します(権限 0600)。個人の使用量情報が含まれているため、共有しないでください。トークンとヘッダーは保存しません。
- 使用量の更新間隔と言語の設定(UserDefaults)。

## 既知の制限

- **Max 5x アカウント1つでのみ検証**しています。他のプラン(Pro、Team、Enterprise、API など)は検証できていません。
- Fable の上限とクレジット(追加使用)が**有効な状態の応答形式は確認できておらず、推測**で実装しています。実際に確認できた応答では、どちらも無効でした。
- セッションのリセット権(チケット)の数は、実際の応答にフィールドが見つからなかったため**サポートしていません**。
- **応答待ち**の状態は、`claude` バイナリの解析で分かった値(`waiting`)に基づいており、実際のセッションでは確認できていません。
- セッション名のクリックは**アプリ単位で最前面に表示する**だけで、アプリ内の特定のタブ/ウィンドウ/セッションを選ぶことはありません。tmux のように親プロセスの連鎖が途切れる場合は、アプリを見つけられません。
- 署名していない(一時署名の)ローカルビルドのみをサポートしており、配布用のバイナリは提供していません。

```sh
swift test                  # 全ユニットテスト
swift run RenderPreview     # メニューバー画像/ドロップダウンの PNG を描画 -> build/preview/
```

`RenderPreview` はプロジェクトルートで実行する必要があり、ライト/ダーク別の PNG とメニュー構造のテキスト(`menus.txt`)を `build/preview/` に生成します。

### `--probe-usage` 診断フラグ

```sh
build/ClawdCounter.app/Contents/MacOS/ClawdCounter --probe-usage
```

ログイン済みの状態で、使用量 API のクエリ違いの応答を `~/Library/Application Support/ClawdCounter/probe/` に保存します。違いのあるクエリは Claude Code のバイナリで見つけた非公式の値で、意味は確認できていません。**保存される応答には個人の使用量情報が含まれるため、issue に投稿する前に必ず伏せてください。**

構造については [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)（韓国語）を参照してください。

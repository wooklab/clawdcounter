# ClawdCounter

[한국어](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

ClawdCounter 是一款非官方的 macOS 菜单栏应用，在菜单栏中显示 Claude 的用量限额（5 小时 / 每周）以及本地 Claude Code 会话的状态。它与 Anthropic 无关，所依赖的是未公开文档的接口，这些接口随时可能变更或被封锁。界面支持韩语、英语、简体中文和日语。

## 功能

- **菜单栏显示**：`5 小时限额剩余时间 | [5 小时进度条 / 每周进度条] | ● 活跃数 / ○ 空闲数 | ✋ 等待响应`
  - 5 小时窗口未处于活跃状态时，剩余时间位置显示 `–`；如果根本没有 5 小时限额，则只显示每周进度条。
  - 只有存在等待响应的会话时才会显示 `✋`，达到 2 个及以上时会同时显示数量。
  - 退出登录状态下显示 `需要登录`，登录过期后显示 `需要重新登录`。
- **用量四档颜色**：进度条和下拉菜单中的颜色，以界面上显示的整数百分比（四舍五入后）为准。

  | 用量 | 颜色 |
  |---|---|
  | 0–49% | 绿色 |
  | 50–79% | 黄色 |
  | 80–94% | 橙色 |
  | 95% 及以上 | 红色 |

- **下拉菜单**（以分隔线划分区块）
  1. 限额：5 小时 / 每周 / Fable。显示进度条、百分比和剩余时间。如果 API 响应中没有对应的限额，则不显示该行。
  2. 额度：额外用量（额度）的金额。已知总量时显示为 `已用 / 总量`。
  3. 会话：按状态分组的标题和会话名列表（每种状态最多显示 8 个，超出部分显示为 `另外 N 个`）。
  4. 登录 Claude / 退出 Claude 登录、设置（登录时自动启动、用量刷新间隔 1·2·5 分钟、语言）。
  5. 退出。
- **三种会话状态**：● 活跃（绿色）/ 等待响应（菜单栏为 ✋，下拉菜单中为黄色 ●）/ ○ 空闲。正在运行的子代理会按每个 1 个计入活跃会话，并以 `↳ 描述` 的形式列出。
- **点击会话名**：把该会话所在的应用（终端、VS Code、Claude 桌面版等）切换到前台。
- **多语言**：支持 한국어、English、简体中文、日本語 四种语言。默认跟随系统语言，也可以在设置中切换语言。

## 系统要求

- macOS 14 及以上
- Xcode 和 Swift 6 工具链（`swift-tools-version: 6.0`）

## 安装 / 构建

```sh
git clone https://github.com/wooklab/clawdcounter.git
cd clawdcounter
scripts/build_app.sh        # 结果：build/ClawdCounter.app
open build/ClawdCounter.app
```

应用仅在菜单栏运行（`LSUIElement`），因此没有 Dock 图标。

### 首次运行警告

构建脚本只做临时（ad-hoc）签名（`codesign --sign -`）。自行构建的应用通常可以无警告运行，但从其他地方下载或压缩后转移过来的应用，可能会弹出 Gatekeeper 警告。遇到这种情况，请使用下列方式之一。

- 在 Finder 中右键点击 `build/ClawdCounter.app` → **打开**
- 或者执行 `xattr -dr com.apple.quarantine build/ClawdCounter.app`

`xattr` 命令**只能用于你自己构建的应用**。不要对来源不明的应用使用。

### 钥匙串确认窗口

登录后，令牌（访问令牌 / 刷新令牌）会保存到应用专用的钥匙串项 `ClawdCounter-credentials` 中。重新构建或更新应用后，临时签名会发生变化，钥匙串访问确认窗口可能会再次弹出，此时选择**始终允许**即可。

## 使用方法

1. 启动应用后，菜单栏会显示 `需要登录`。
2. 点击菜单栏项目，选择**登录 Claude**。默认浏览器会打开，完成登录后应用会自动获取用量。
3. 如果无法启动本地回调服务器，则会切换为把浏览器中显示的代码粘贴到应用中的方式。
4. 用量默认每 1 分钟刷新一次（可在设置中选择 1·2·5 分钟），打开菜单时也会刷新。
5. 在设置 → 语言中可以切换显示语言。切换后会立即应用到菜单栏、下拉菜单和设置窗口。

## 隐私

**读取的本地文件**（均为只读）

- `~/.claude/sessions/*.json`：会话状态（`status`）、名称、工作目录、会话 ID 等
- `~/.claude/projects/*/<sessionId>/subagents/*.meta.json`：子代理的描述和是否已结束
- 同一位置的子代理 `jsonl` 文件**只检查修改时间**，不读取内容。

**网络**

- 登录：`claude.com`（在浏览器中打开认证页面）、`platform.claude.com`（令牌的签发 / 刷新 / 撤销）
- 用量查询：`api.anthropic.com`
- 不会向第三方服务器发送数据，也没有分析 / 遥测上报。

**凭据**

- 不会读取或写入 Claude Code 的凭据（钥匙串项、`~/.claude` 中的认证信息）。只使用应用通过自己的 OAuth 登录获得的令牌。
- **退出登录**时，会从钥匙串中删除应用的令牌，并尝试请求服务器撤销令牌（即使失败，本地删除依然有效）。

**应用写入磁盘的内容**

- `~/Library/Application Support/ClawdCounter/last_usage_raw.json`：为方便调试，会覆盖写入**最近一次用量 API 响应的原文**（权限 0600）。其中包含个人用量信息，请勿分享。不会保存令牌和请求头。
- 用量刷新间隔和语言设置（UserDefaults）。

## 已知限制

- **仅在一个 Max 5x 账号上验证过**。其他套餐（Pro、Team、Enterprise、API 等）尚未验证。
- Fable 限额和额度（额外用量）**处于启用状态时的响应格式没有确认过，是按推测实现的**。在实际看到的响应中，这两项都处于未启用状态。
- 会话重置券（ticket）的数量在实际响应中没有找到对应字段，因此**不支持**。
- **等待响应**状态基于通过分析 `claude` 二进制文件得到的值（`waiting`），尚未在实际会话中确认。
- 点击会话名只会**以应用为单位切换到前台**，不会选中应用内的某个特定标签页 / 窗口 / 会话。像 tmux 这样父进程链断开的情况，找不到对应的应用。
- 只支持未签名（临时签名）的本地构建，不提供用于分发的二进制文件。

## 开发

```sh
swift test                  # 全部单元测试
swift run RenderPreview     # 渲染菜单栏图像 / 下拉菜单 PNG -> build/preview/
```

`RenderPreview` 必须在项目根目录下运行，它会在 `build/preview/` 中生成浅色 / 深色两套 PNG 以及菜单结构文本（`menus.txt`）。

### `--probe-usage` 诊断参数

```sh
build/ClawdCounter.app/Contents/MacOS/ClawdCounter --probe-usage
```

在已登录的状态下，把用量 API 各种查询变体的响应保存到 `~/Library/Application Support/ClawdCounter/probe/`。这些变体查询是从 Claude Code 二进制文件中看到的非官方值，其含义尚未确认。**保存的响应包含个人用量信息，提交到 issue 之前务必先遮盖。**

架构说明请参阅 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)（韩语）。
